# QuantFolio 📈

QuantFolio is a quantitative financial analytics engine and portfolio optimization dashboard built in Python. 

## Features
* **Data Ingestion:** Automated fetching of historical stock data using `yfinance`.
* **Algorithmic Backtesting:** Vectorized backtesting of trading strategies (SMA Crossover, Mean Reversion).
* **Portfolio Optimization:** Modern Portfolio Theory (MPT) implementation to find the Efficient Frontier.
* **Interactive Dashboard:** A Streamlit UI for visualizing asset performance and strategy returns.
